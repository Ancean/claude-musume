# Claude娘

<img src="buddy-art/idle.png" width="220" align="right">

由于我实在受不了了每次点击右下角的额度窗口查看额度和估算用量，所以制作了一个桌宠（感谢image2.5和opus5.5大人神力）。

这是什么：这是一个Windows 桌面宠物。一个捧书的小姑娘，脚下显示 Claude 的 5 小时与 7 天额度，会闲聊、会提醒额度告急，会在Claude Code 完成任务时为你欢呼。随附一个 Claude Code 插件，把额度、上下文、花费和任务进度实时同步给她（不这样的话她没法即时同步状态）。

声明：这是粉丝自制的非官方项目，与 Anthropic 没有任何关系，也没有得到其认可。Claude 是 Anthropic 的商标。

- 安装、使用和全部功能说明见 [buddy-pet/README.md](buddy-pet/README.md)
- `buddy-pet/`：程序、插件、打包脚本
- `buddy-art/`：角色图和生图提示词
