# Claude娘

<img src="buddy-art/idle.png" width="220" align="right">

Windows 桌面宠物：一个捧书的小姑娘停在屏幕角落，脚下显示 Claude 的 5 小时与 7 天额度，会闲聊、会提醒额度告急，Claude Code 做完任务时为你欢呼。随附一个 Claude Code 插件，把额度、上下文、花费和任务进度实时同步给她。

这是粉丝自制的非官方项目，与 Anthropic 没有任何关系，也没有得到其认可。Claude 是 Anthropic 的商标。

- 安装、使用和全部功能说明见 [buddy-pet/README.md](buddy-pet/README.md)
- `buddy-pet/`：程序、插件、打包脚本
- `buddy-art/`：角色图和生图提示词
