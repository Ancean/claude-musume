# Claude娘（桌面宠物）

停在桌面上的捧书少女，脚下的卡片显示 Claude 的 5 小时与 7 天额度。随附的 Claude Code 插件让重置时间变成准确值，还能看到当前会话的上下文长度和花费，Claude Code 做完一个任务时她会提醒你。只支持 Windows。

这是粉丝自制的非官方项目，与 Anthropic 没有任何关系，也没有得到其认可。Claude 是 Anthropic 的商标。

## 安装

普通用户用安装程序 `Claude娘-安装程序.exe`（按下文“打包”自己生成，或者向作者要）。它装在当前用户的 `%LOCALAPPDATA%\Programs\Claude娘`，不需要管理员权限，会同时：

- 把 Claude Code 插件装到 `%USERPROFILE%\.claude\skills\claude-buddy-bridge`；
- 在开始菜单建快捷方式，可选桌面快捷方式；
- 可选“开机后常驻小哨兵”（默认勾选），Claude 桌面端打开时叫她出来。

卸载在“设置 › 应用”或开始菜单里的“卸载 Claude娘”，会一并结束正在运行的她、删掉插件和自动运行登记；你改过的台词 `lines.json` 和设置 `config.json` 会留在安装文件夹里，重装后还在，不要了可以手动删掉。

从源码运行需要 Python 3、PyQt5 和 Pillow：`pythonw pet.pyw` 或双击 `启动桌宠.bat`。插件会在她第一次启动时自动装上。

## 启动与退出

平时不用管她：Claude 桌面端的窗口打开后几秒内她会自己出来，窗口关掉后 3 到 6 秒内她挥挥手、说一句再见后退出，细节见下文“跟随 Claude 启动和退出”。

想手动叫她时点开始菜单里的“Claude娘”（源码运行时双击 `启动桌宠.bat`），重复启动不会开第二只。手动退出是右键她选“退出”，或右键任务栏托盘里她的头像选“退出”。

## 操作

| 操作 | 效果 |
| --- | --- |
| 鼠标移到她身上 | 歪头、换成笑脸（几张笑脸差分按权重随机挑）；没有笑脸图时改为脸红 |
| 左键点她 | 压扁再弹回、冒爱心、轻轻响一声、说一句话；连着点，声音一个比一个高 |
| 3 秒内连点 5 下 | 她鼓起脸抗议 |
| 按住拖动 | 换位置，松手后位置会记住；拖到屏幕边松手会贴在边上（见“贴边”） |
| 点脚下的额度胶囊 | 展开成详细卡片，8 秒后自动收起（鼠标还停在她身上时等移开再收）；展开时再点一下马上收起 |
| 鼠标停在额度卡片上 | 提示框显示额度详情：消耗速度、预计几点用完、上下文和花费 |
| 点对话气泡 | 正在逐字显示时先显示整句，再点一下收起 |
| 右键 | 菜单，见下 |

右键菜单的第一层是常用操作：隐藏或显示、立即刷新、管理台词、鼠标穿透、置顶、回到右下角、退出。其余开关收在“设置”里：大小、额度卡片的样式、闲聊频率、提示音（开关、音量、任务结束音、试听、自定义声音文件夹）、任务完成提醒、没人理时打瞌睡、感知 Claude Code 工作状态、跟随 Claude 启动和退出，以及 Claude Code 插件的安装状态。托盘图标的右键菜单和这里一样，单击托盘图标她会报一下额度。

## 额度卡片

脚下的卡片平时是简洁的胶囊，只有 5 小时和 7 天两个百分比；点一下展开成详细卡片，过一会儿自动收起。在“设置 › 额度卡片”里选“总是详细”就一直显示详细卡片。贴边时只显示胶囊，点了也不展开。

详细卡片里 5 小时和 7 天各占一行：进度条、已用百分比、“重置于”几点。重置时间是推算的还是来自插件的准确值，在鼠标停在卡片上时的提示框里能看出来（推算的带“约”字）。进度条后面颜色更浅的一段，是照最近的速度到重置时会用到的位置，一眼能看出会不会提前用完。最近有动静的那个 Claude Code 会话装着插件时，卡片多一行它的上下文 token 和花费；那个会话没有插件数据（比如是装插件之前开的）时这一行不显示，不会拿别的会话的数字顶替。“最近有动静”看的是 `%USERPROFILE%\.claude\projects` 下会话记录的修改时间，文件名就是会话 id，不读内容。数值 70% 起变橙色，90% 起变红；数据超过 40 分钟没更新时整行变灰。

鼠标停在卡片上时的提示框里，每项除了百分比和重置时间，还有最近的消耗速度（5 小时额度看最近一小时，7 天额度看最近一天）和预测：照这个速度几点用完，或者到重置时大约用到多少。下面是上下文、花费和数据的更新时间。

## 额度数据从哪来

有两个来源，谁的读数新就用谁，都不涉及登录凭据。

第一个是 Claude 桌面端大约每 15 分钟写一次的 `%APPDATA%\Claude\plan-usage-history.json`，宠物每 20 秒检查一次，只读其中的百分比。文件里没有重置时间，所以是从历史推算的：5 小时额度从空闲后的第一次使用开始计时，7 天额度在每周固定的时刻重置。误差一般在 10 分钟以内。

第二个是随附的 Claude Code 插件 `claude-buddy-bridge`。它在 Claude Code 里读引擎自己报告的额度、上下文和花费，写到 `%USERPROFILE%\.claude\buddy-pet\live\<会话 id>.json`，每个会话一个文件，额度每变动一个百分点、每开始或结束一轮对话都会更新，另外每分钟写一次心跳。文件里只有百分比、重置时间、上下文 token 数、花费和每轮的起止时间，不写提示词、回答或项目路径。超过 3 天没更新的文件由宠物顺手删掉。

## Claude Code 插件

插件装在 `%USERPROFILE%\.claude\skills\claude-buddy-bridge`，只有三个文件。安装程序会装好它；她每次启动时也会检查一遍，没装或者和随附的版本不一致就自动装上或更新。右键菜单“设置 › Claude Code 插件”会显示装没装、是不是和随附的版本一致、现在有没有会话在发数据，也能手动“安装”或“更新”，都是从随附的 `claude-plugin` 文件夹复制这三个文件过去。安装位置或它的上一级是符号链接、目录联接时不会安装，免得写到别的地方。

插件只在新开的 Claude Code 会话里加载，已经开着的会话要重开一次。卸载时删掉 `claude-buddy-bridge` 文件夹即可，之后新开的会话不再加载；`.claude\buddy-pet` 文件夹也可以一起删。没装插件时宠物照常工作，只是重置时间是推算的，没有上下文和花费，任务完成的判断也粗一些（见下）。

插件写数据的路径是固定的，和宠物放在哪里、是不是打包成 exe 无关，所以以后打包或挪位置都不用改插件。

## 她的反应

- 5 小时额度上涨时，卡片上方飘出 `+N%`；插件每涨 1% 就更新一次，所以 45 秒内的涨幅会攒在一起飘。
- 跨过 50%、70%、90% 时提醒你；70% 起换成着急的表情并有提示音。7 天额度跨过 70%、90% 时也会提醒。
- 额度紧张时头边一阵一阵地冒小特效，每阵三四秒，换着来、不连着重复，中间歇一会儿：70% 起是汗滴、叹气的白烟、转圈的晕晕线和头顶的阴影竖线；90% 起歇得更短，还会冒感叹号和一朵下雨的小乌云。她笑着、被摸着或欢呼时不冒。额度宽松又闲着时，偶尔哼出两个小音符。任务出错时她着急的那几秒一直冒汗。
- 照最近的速度，5 小时额度会在一个半小时内、而且在重置之前用完时，她会提醒你放慢一点（已用 30% 以上才提醒，两小时内最多一次）。
- 额度重置时欢呼着跳两下、响铃。
- Claude Code 在干活时她低头看书，头顶出现思考气泡。装了插件的会话直接看插件报告的状态；其余会话（没装插件，或者装插件之前就开着的）看 `%USERPROFILE%\.claude\projects` 下会话记录的修改时间，不读内容。
- Claude Code 做完一个超过 1 分钟的任务时，她欢呼、响一声并说用了多久；你正看着 Claude 的窗口时不响。任务因为出错结束时她会着急地提醒你，这一项需要插件。没装插件时，会话记录写了一阵又安静 45 秒以上就算做完，偶尔会把模型长时间思考误当成做完。菜单里可以关掉这项提醒。
- 20 分钟没人碰她、Claude 也没在干活，她就打瞌睡，头边飘 Z，闲聊只剩梦话。鼠标移上去不会吵醒她，点一下才醒。
- 她刚出来时挥手打招呼，退出前挥手道别。打招呼优先用闲聊区里带【今天第一次】【见面】条件的台词，挑不到时用当前时段的问候（见“台词”）。
- 隔一阵随口说一句，频率在“设置 › 闲聊”里选：一句接一句（上一句的气泡消失后两三秒就说下一句）、很频繁（约 1 分钟）、适中（约 5 分钟，默认）、偶尔（约 20 分钟）、几乎不说（约 1 小时）或关闭。闲聊以“闲聊区”为主，也会混进问候、报额度、陪 Claude 干活等几类；不打断正在显示的气泡；打瞌睡时只说梦话，而且至少隔 3 分钟。

## 贴边

把她拖到屏幕左、右、上边附近（身体离边 16 像素以内，或者拖出了边）松手，她会换成贴边的样子贴在那条边上：左右两边扒着屏幕边探头，上边单手吊着，下边从屏幕底探出半个身子。下边要把整个窗口（连卡片）拖到碰到屏幕底才会吸住，免得放在右下角的默认位置也被吸住。贴边时脚下只显示简洁的额度胶囊；点她、说话、提醒都照常，表情和动作图不切换。按住她往外拖就离开边，恢复平常的样子。贴边的位置会记住，下次启动还贴在那里；“回到右下角”会让她离开边。

贴边图在 `buddy-art` 里，叫 `edge_left.png`、`edge_right.png`、`edge_top.png`、`edge_bottom.png`，也可以像表情一样放多张差分（`edge_left_说明.png`），按权重随机挑。哪条边没有图就不吸那条边；只有左边的图时右边用它的镜像。每张图显示多大在 `edge_dock.py` 开头的 `EDGE_SCALE` 里调。

## 鼠标穿透

菜单里勾选“鼠标穿透”后，点击会直接落到她下面的窗口，她不会挡住你点东西。这时鼠标停在她身上，她会变淡，方便看清下面的内容。想和她互动时按住 Ctrl 再点、拖或右键，松开 Ctrl 又恢复穿透。托盘菜单任何时候都能用。

## 置顶

她的窗口一直带着置顶标记，但 Windows 在显示桌面、切换虚拟桌面、显示器休眠唤醒等情况之后，偶尔会把置顶窗口排到普通窗口下面，标记却还在，于是被别的窗口盖住。她每 1.5 秒检查一次自己上方有没有普通窗口，有就回到置顶层的最上面，不抢焦点、不移动位置。

前台是全屏程序（全屏看视频、玩游戏、放幻灯片），而且和她在同一块屏幕上时，她会先躲起来，全屏结束后自己回来。判断依据是 Windows 自己用来暂停通知的那个状态。全屏期间想叫她出来，单击托盘图标或在托盘菜单里选“显示”，这次全屏期间她就不再躲。菜单里取消勾选“置顶”后，她变回普通窗口，也不再躲全屏。

## 声音

提示音是程序合成的木琴一样的柔和音色，每个音都有一点渐起，不会突然一响：点她是五声音阶里的单音，任务完成是轻轻的“叮咚”，额度重置是上行的琶音，额度告急是两个往下走的低音。音量在“设置 › 提示音 › 音量”里分小声、适中、大声三档，“试听”可以逐个听。

一轮回复完成时的任务结束音在“设置 › 提示音 › 任务结束音”里选：默认是 Minecraft 的经验球音效，另一个预设是 A，也可以选回合成的“叮咚”、自选一个 wav 文件，或者选一个文件夹当音效组，每次从里面随机放一个。选中后马上试听一次。自选文件只认 wav（Windows 自带的播放只支持 PCM 格式的 wav），放不了的文件会被跳过，全都放不了时退回经验球；没有截取片段的功能，想要某一段请先用别的工具剪好。两个预设放在 `sound-presets` 文件夹，来自 [DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget) 桌宠项目（MeteorNOX，MIT 许可）。经验球音效版权属于 Mojang，所以源码仓库里不带 `minecraft-exp-orb.wav`，这时默认的任务结束音是音效 A；想要经验球的话自己把同名 wav 放进 `sound-presets` 即可。

想换掉其他提示音，把 wav 文件放进 `sounds\自定义`（菜单里“打开自定义声音文件夹”可以直接打开），文件名用 `done.wav`（任务完成，只在任务结束音选“叮咚”时用）、`chime.wav`（额度重置）、`warn.wav`（额度告急）或 `pat.wav`（点她）；也可以用 `pat1.wav` 到 `pat5.wav` 分别替换连点时的五个音。不放就用合成的。

## 换图

角色图在上一级的 `buddy-art` 文件夹。`idle.png`（平时）是必需的；`blink.png`（闭眼）、`happy.png`（笑）、`worried.png`（着急）、`working.png`（看书）和下面五种动作图现在都有，生图提示词见 `buddy-art\生图提示词.md`：

| 文件名 | 什么时候用 | 没有这张图时 |
| --- | --- | --- |
| `drag.png` | 被拖着走 | 平时的表情，身体随拖动倾斜 |
| `sleep.png` | 打瞌睡 | 闭眼图 |
| `wave.png` | 打招呼、道别 | 笑脸 |
| `cheer.png` | 任务完成、额度重置 | 笑脸 |
| `pout.png` | 连点 5 下抗议 | 着急的表情 |

换图时保持与 `idle.png` 同样的画布尺寸，人物位置尽量不动，改完重启宠物生效。汗滴、感叹号、怒气符号、Z、爱心这些特效由宠物自己画，位置在 `buddy-art\anchors.json` 里调；`pout.png` 自己画了怒气符号，用这张图时宠物就不再叠画一个。

同一种表情或动作可以放多张差分，文件名写成“名字_说明”，比如现在的 `happy_浅笑.png`、`worried_赔笑.png`、`working_托腮.png`。每次切换到这种表情时按权重随机挑一张；同一种表情持续久了，每隔 20 到 40 秒也会重新挑一次。权重写在 `buddy-art\weights.json`，键是文件名去掉扩展名，没写的按 1 算，写 0 就不再出现。闭眼图按名字配对：`idle.png` 配 `blink.png`，`idle_xx.png` 配 `blink_xx.png`，没有配对的闭眼图时那张就不眨眼。

## 台词

台词在右键菜单的“管理台词”里改。左边是各类台词和句数，第一类就是“闲聊区”，鼠标停在分类上会提示这一类什么时候说；右边一行一句（想在气泡里换行就写 `\n`），“插入字段”可以把实时数据插到光标处（额度百分比、剩余、重置时间、每小时消耗、预计用完的时刻、上下文、花费、任务用时），“新增一句”跳到最后另起一行，“试说这一句”让她当场把光标所在那句说出来。字段写错的句子会标红，到时候会被跳过；缺数据的句子（比如没装插件时提到上下文的）也会自动跳过。按“保存”或 Ctrl+S 后马上生效，不用重启。

“闲聊区”的句子可以加条件，写在句子开头，用“条件”按钮选就行（选“随机”去掉条件），也可以手写成 `【见面】你回来啦`：

| 条件 | 什么时候说 |
| --- | --- |
| 不加 | 闲聊时随机说 |
| 【今天第一次】 | 每天第一次见面时说 |
| 【见面】 | 见面时约一半机会说；每天第一次见面时，没有【今天第一次】的句子也用它 |
| 【早上】【白天】【傍晚】【深夜】 | 闲聊时随机说，但只在那个时段（和问候台词的时段一样） |

“见面”指她刚出来（启动、跟着 Claude 出来）、打瞌睡时被点醒或拖醒，以及从隐藏里叫出来。被叫醒时没挑到见面台词就说“被叫醒”那类。见面台词同一句每天最多说一次，“每天”从早上 5 点算起，说过哪些记在 `met.json`，重启后同一天也不重复。见面类可以和时段一起用，比如 `【见面】【深夜】这么晚还来？`。条件只在闲聊区里有用，写在别的分类里会标红。

左下角的“新建分类”可以加自己的分类，比如“口头禅”“彩蛋”，可以重命名和删除。自定义分类在闲聊时和其他台词一起按权重随机抽：闲聊区 6、当前时段的问候 1、报额度 2、报会话 1、Claude 干活时的陪伴台词 3，每个自定义分类 3。

台词存在 `lines.json`，也可以直接编辑这个文件，自定义分类在其中的 `custom` 下。

| `follow_claude.pyw` | 常驻小哨兵，Claude 打开时叫她出来 |
| `claude_app.py` | 判断 Claude 桌面端开没开、是不是在前台 |
| `desktop_win.py` | 保持置顶、判断全屏、鼠标穿透 |
| `snapshot.py` | 自检：把各种状态渲染成 PNG，由 `python pet.pyw --snapshot 目录` 调用 |
| `line_tags.py` | 闲聊区台词的【条件】规则 |
| `lines.json` | 你的台词，首次运行时生成，不进源码仓库 |
| `met.json` | 今天说过哪些见面台词，自动生成；删掉就当今天还没见过面 |

## 跟随 Claude 启动和退出

“Claude 开着”以 Claude 桌面端的主窗口为准：最小化也算开着；点关闭后不论程序彻底退出还是缩到托盘，都算关了。Claude Code 命令行版没有自己的窗口，单独开它不算。

- 退出由她自己负责：每 3 秒看一次，连续两次看不到 Claude 的窗口就道别退出。Claude 没开时用 bat 叫出来的她，要等 Claude 开过再关才会退出。台词窗口开着时她会等窗口关掉再走。
- 启动由常驻的小哨兵负责：安装版是 `Claude娘.exe --follow`，源码版是 `follow_claude.pyw`。它在登录 Windows 时自动运行，不加载界面库，约占 20 到 30 MB 内存，每 3 秒检查一次；看到 Claude 的窗口从无到有就启动桌宠。Claude 开着时你手动退出了她，它不会马上把她叫回来，下次打开 Claude 才会。
- 菜单里的“跟随 Claude 启动和退出”可以整个关掉这套行为，设置存在 `config.json` 里，哨兵也会遵守。

登录时的自动运行登记在注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下，名称 `ClaudeBuddyPet`，可以在任务管理器的“启动应用”里禁用。安装版由安装程序登记、卸载时删除。源码版要自己登记，把下面的路径换成你的 pythonw 和 `follow_claude.pyw`：

```powershell
Set-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name 'ClaudeBuddyPet' -Value '"<pythonw.exe 的路径>" "<follow_claude.pyw 的路径>"'
```

去掉时删除这一项登记即可：

```powershell
Remove-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name 'ClaudeBuddyPet'
```

## 打包

`python installer\build.py` 用 PyInstaller 生成 `dist\Claude娘` 文件夹，再用 Inno Setup 6 做成 `dist\Claude娘-安装程序.exe`；只要文件夹时加 `--no-installer`。需要先 `pip install pyinstaller`，再装 [Inno Setup 6](https://jrsoftware.org/isdl.php)；简体中文的安装界面翻译在第一次打包时从 Inno Setup 的官方仓库下载。

打包后的程序把设置、台词、声音和日志写在 exe 旁边，所以装在用户自己的文件夹里；角色图先找 exe 旁边的 `buddy-art`（方便换图），找不到再用打包进去的。打包版没有带 numpy 和 scipy，换进去的角色图要是透明背景的 PNG。同一个 exe 带 `--follow` 参数时只当哨兵。插件写数据的位置不受影响。

## 依赖

Python 3、PyQt5 和 Pillow；角色图没有透明背景时还会用到 numpy 和 scipy。`follow_claude.pyw`、`claude_app.py`、`desktop_win.py`、`usage_data.py` 和 `sounds.py` 只用标准库。`python pet.pyw --snapshot 目录` 可以把各种状态渲染成 PNG 检查画面，不显示窗口；`python claude_app.py` 可以查看当前是否认出了 Claude 的窗口。
